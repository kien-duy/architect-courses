Đây là khóa học **không chính thức** giúp bạn chuẩn bị cho chứng chỉ **Claude Certified Architect — Foundations**. Khóa học không do Anthropic thực hiện hay bảo trợ.

Kỳ thi kiểm tra khả năng ra quyết định đánh đổi khi xây dựng ứng dụng thực tế với Claude, xoay quanh bốn công nghệ: Claude Code, Claude Agent SDK, Claude API và Model Context Protocol (MCP).

## Khóa học dành cho ai

Lập trình viên đã quen viết code nhưng mới dùng Claude API, Agent SDK hoặc Claude Code. Bạn không cần biết trước về agent. Thuật ngữ kỹ thuật được giữ nguyên tiếng Anh (`tool_use`, `stop_reason`, subagent, hook) vì đề thi dùng tiếng Anh.

## Đề thi gồm những gì

| Thông số | Giá trị |
|---|---|
| Dạng câu hỏi | Trắc nghiệm, 1 đáp án đúng trong 4 |
| Thang điểm | 100–1000, đạt từ **720** |
| Trừ điểm khi sai | Không. Luôn trả lời mọi câu |
| Tình huống | 4 trong 8 tình huống, chọn ngẫu nhiên |

| Domain | Tỉ trọng | Trong khóa này |
|---|---|---|
| 1. Kiến trúc agent và điều phối | **27%** | 6 bài, lab, quiz |
| 2. Thiết kế tool và tích hợp MCP | **18%** | 5 bài, lab, quiz |
| 3. Cấu hình và quy trình Claude Code | **20%** | 6 bài, lab, quiz |
| 4. Prompt engineering và structured output | **20%** | 6 bài, lab, quiz |
| 5. Quản lý context và độ tin cậy | **15%** | 6 bài, lab, quiz |

Cuối khóa có [đề thi thử 60 câu tính giờ](./on-tap/thi-thu/), chia câu theo đúng tỉ trọng trên.

Các số liệu về đề thi lấy theo hướng dẫn thi chính thức tại thời điểm viết. Hãy kiểm tra lại trên [trang đăng ký của Anthropic](https://anthropic.skilljar.com/claude-certified-architect-foundations-access-request) trước khi thi.

## Mỗi bài học gồm gì

1. **Nội dung** đọc trong 10–15 phút, một ý chính mỗi bài.
2. **Tài liệu chính thức mở ngay trong trang.** Link có ký hiệu ◨ mở ngăn trượt bên phải, bạn không phải rời bài đang đọc.
3. **Kiểm tra cuối bài** 1–3 câu tiếng Anh như đề thật. Đúng hết trong một lượt thì bài được tích hoàn thành.
4. **Lab** cuối mỗi domain, chạy bằng Claude Code với tài khoản đang đăng nhập, không cần API key.
5. **Đánh giá** 1–5 sao và ô góp ý cải thiện bài.

Xem [Cách dùng trang học](./bat-dau/cach-hoc/) để biết về checklist nổi và nút lưu tiến trình.
