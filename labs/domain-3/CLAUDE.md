# shopkit

Dịch vụ đặt hàng nhỏ viết bằng Python 3. Đây là dự án mẫu của lab Domain 3.

## Lệnh

- Chạy test: `python3 -m unittest discover -s tests`

## Quy ước

- Tiền luôn là số nguyên, đơn vị đồng. Không dùng `float` cho tiền. Tên biến và tham số chứa tiền kết thúc bằng `_vnd`.
- Mọi hàm public có type hint và docstring một dòng bằng tiếng Việt.
- Trả lời bằng tiếng Việt, ngắn gọn.
- File sinh ra trong lúc làm việc ghi vào `out/`.
